# 每日图鉴 · Daily Gallery

每天更新的韩团成员 / 剧集女星人物图鉴。手机浏览器直接打开即可，卡片式下滑浏览，支持按类别、国家筛选与名字/团体搜索。

**线上地址**：https://hlm428.github.io/goddess-gallery/

照片全部是真实人物照片（维基共享资源的活动新闻照、经纪公司提供的官方新闻照等），**没有 AI 生成图**。每张卡片底部都标了图源、作者与授权协议。

## 文件都在哪

```
goddess-gallery/
├── index.html          页面骨架（不写死任何人物资料）
├── styles.css          样式（手机优先的响应式布局）
├── app.js              筛选 / 搜索 / 照片轮播 / 放大查看 / 分页加载
├── data/
│   └── people.json     ★ 所有人物 + 照片链接都在这里，每天只改这个文件
├── images/             本地照片（34 张，约 3.5 MB，不外链，不会失效）
├── .nojekyll           让 GitHub Pages 原样发布
└── README.md           本说明
```

本地想预览（直接双击 index.html 会被浏览器的本地文件安全策略拦住 JSON，需要用本地服务器）：

```bash
cd goddess-gallery
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

改完文件推送即可生效（GitHub Pages 部署在 `main` 分支根目录）：

```bash
git add .
git commit -m "add today's profiles"
git push
```

## 每天怎么加新人

打开 `data/people.json`，在 `people` 数组里追加一个对象。**字段含义**：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 英文小写 + 连字符，全站唯一，也是图片文件名前缀，例如 `ive-liz` |
| `name` | 是 | 中文名；没有通用中文译名时直接写艺名 |
| `originalName` | 是 | 原名（韩文 / 英文 / 日文全名 + 艺名） |
| `alias` | 否 | 其他译名、异译，方便搜索；没有就写 `""` |
| `group` | 是 | 韩团填团体名；剧集女星填代表剧 |
| `role` | 是 | 身份，如「歌手 · 队长」「演员 · 编剧」 |
| `countries` | 是 | 数组，用于国家筛选，如 `["韩国"]`、`["中国台湾"]`、双重背景写 `["韩国","加拿大"]` |
| `category` | 是 | `"kpop"` 或 `"drama"` |
| `birthDate` | 是 | `"YYYY-MM-DD"`；**年龄由页面按当天日期自动算，不用手填** |
| `height` | 是 | 字符串，如 `"167 cm"`；来源不一致就写「约 157–160 cm」，查不到写 `"未公开"` |
| `weight` | 是 | **只有官方 profile / 可靠媒体明确公布过才填数值**，否则一律写 `"未公开"`，绝不编造 |
| `bio` | 是 | 1–2 句客观背景介绍 |
| `works` | 是 | 2–4 个真实代表作，字符串数组 |
| `note` | 否 | 需要澄清的备注（合约状态、角色换角、身高分歧等）；没有写 `""` |
| `photos` | 是 | 照片数组，格式见下 |
| `addedAt` | 是 | 加入图鉴的日期 `"YYYY-MM-DD"`，决定进不进「今日更新」 |

**最小示例**（复制后改成真实资料即可）：

```json
{
  "id": "example-person",
  "name": "示例姓名",
  "originalName": "Example Name · 예시",
  "alias": "",
  "group": "EXAMPLE",
  "role": "歌手 · 舞者",
  "countries": ["韩国"],
  "category": "kpop",
  "birthDate": "2005-01-01",
  "height": "165 cm",
  "weight": "未公开",
  "bio": "2025 年随团体出道，担任主唱。",
  "works": ["《出道曲》（2025）", "《第二张单曲》（2026）"],
  "note": "",
  "photos": [
    {
      "file": "images/example-person-1.jpg",
      "caption": "2026 年活动照",
      "credit": "Wikimedia Commons / 摄影者",
      "license": "CC BY 4.0",
      "source": "https://commons.wikimedia.org/wiki/File:...",
      "addedAt": "2026-11-07"
    }
  ],
  "addedAt": "2026-11-07"
}
```

## 每天怎么加新照片

两种情况：

1. **给已有人物加照片**：找到那个人，往 `photos` 数组里再追加一个对象，`file` 用 `images/人物id-2.jpg`、`-3.jpg`……卡片会自动出现左右箭头、圆点和滑动切换，不用改任何页面代码。
2. **新人物的第一张照片**：`file` 用 `images/人物id-1.jpg`。

照片文件放进 `images/` 目录即可（建议 JPG、宽 700–900px、单张 < 300 KB，手机上加载才快）。

`photos` 里每个对象的字段：

| 字段 | 说明 |
| --- | --- |
| `file` | 本地相对路径，**必填** |
| `caption` | 照片说明，显示在卡片底部与放大查看里 |
| `credit` | 摄影者 / 来源署名 |
| `license` | 授权协议，如 `CC BY 4.0`；非自由授权写「新闻图片（版权归原权利人）」 |
| `source` | 原图页面链接，卡片底部的「图源」可点开 |
| `note` | 可选，说明裁切、来源特殊情况 |
| `focus` | 可选，竖版裁切焦点，如 `"50% 15%"`；不写默认 `"50% 22%"` |
| `addedAt` | 这张照片的加入日期 |

### 「今日更新」怎么判定

页面取**访客手机当天的本地日期**，把 `addedAt`（人物或任一照片）等于该日期的人物放进「今日更新」横滑栏，并统计当天新增照片数。

- 想让某人明天出现在「今日更新」，把 `addedAt` 写成明天的日期即可。
- 当天没有新增时，栏目会自动改成「最近更新」，显示最近一次更新日期的内容，不会空白。
- 只改 `addedAt` 不改别的内容，也能把旧人物重新推到今日栏。
